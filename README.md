# Food Delivery Platform

Микросервисная платформа для доставки еды

## Структура проекта
- \`backend/\` - микросервисы на Spring Boot
- \`frontend/\` - React приложение

## Сервисы
- \`user-service\` - управление пользователями
- \`restaurant-service\` - рестораны и меню  
- \`order-service\` - обработка заказов

## Технологии
- Java 17, Spring Boot, PostgreSQL
- React, Docker
